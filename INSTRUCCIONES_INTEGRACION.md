# Cómo integrar esta entrega en tu proyecto PharmaMobil

1. Copia la carpeta `composeApp/src/...` dentro de tu proyecto respetando los source sets.
2. Si tu proyecto usa otro paquete, reemplaza `pe.edu.upeu.pharmamobil` por el paquete real en todos los archivos.
3. Verifica que Koin y Compose Material 3 ya existan en tu proyecto antes de usar `PlatformModule` y `AcercaDeScreen`.
4. Agrega una navegación o botón que abra `AcercaDeScreen` para que la tercera capacidad sea visible desde la interfaz.
5. Ejecuta Android y toma las capturas requeridas.
6. Ejecuta iOS desde macOS/Xcode y toma las capturas requeridas.
7. Para la evidencia del error, comenta temporalmente un `actual`, compila, captura el error y luego restaura el archivo.
8. Sustituye los pendientes de la documentación por tus resultados literales.
9. Sube el proyecto a tu rama de GitHub y realiza los commits indicados en `docs/GIT_COMMITS.txt`.
