# Evidencias que debes colocar antes de entregar

El documento de la actividad exige evidencias reales de ejecución. No se deben reemplazar por imágenes inventadas.

Coloca aquí archivos con estos nombres:

1. `01_android_precio.png` - producto con precio formateado en Android.
2. `02_ios_precio.png` - el mismo producto con precio formateado en iOS.
3. `03_android_compartir.png` - selector de compartir de Android con texto visible.
4. `04_ios_compartir.png` - hoja de compartir de iOS con texto visible.
5. `05_android_info_dispositivo.png` - pantalla Acerca de en Android.
6. `06_ios_info_dispositivo.png` - pantalla Acerca de en iOS.
7. `07_error_actual_compilador.png` - error literal al comentar temporalmente un `actual`.

Después de tomar la evidencia 7, vuelve a habilitar el `actual` para que el proyecto quede compilable.
